# Sugar Bytes

Developer education + advocacy platform by Katrina Finney.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## V1 sections

- Learn
- The Lab
- Dev Voices
- Developer Tea
- DX Check
- Community
- Speaking
- About
